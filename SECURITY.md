# Security Policy

## Reporting a Vulnerability

Please report security issues through GitHub's **Private Vulnerability
Reporting** (Security tab → "Report a vulnerability") rather than opening a
public issue.

In your report, include:

- Which version / commit you are running
- A description of the vulnerability and its impact
- Steps to reproduce, or a minimal proof of concept
- Any relevant configuration (deployment mode, reverse proxy, etc.)

You should receive an acknowledgement within 2 business days. We ask that you
do not disclose the issue publicly until a fix has been released.

## Supported Versions

The latest `main` branch and the most recent tagged release receive security
fixes. Older versions are not patched — upgrade to the latest release.

## Scope

This project is designed to run in a private/trusted network; see the
[Security Considerations](README.md#security-considerations) section in the
README. Vulnerabilities in third-party components should be reported to their
respective projects.
